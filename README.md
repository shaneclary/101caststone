# 101 Cast Stone — Maison California

> Proportion. Patina. Permanence.

Marketing site for 101 Cast Stone: hand-crafted architectural cast stone — fireplace mantels, columns, balustrades, and custom stonework — made in Atascadero, California since 2001.

**Live domain:** https://101caststone.com

---

## Tech Stack

| Tool | Version | Purpose |
|------|---------|---------|
| Next.js | 14.2 (App Router) | Framework, static prerendering |
| React | 18.3 | UI |
| TypeScript | 5.6 | Type safety |
| Tailwind CSS | 3.4 | Styling (`@tailwindcss/forms`, `@tailwindcss/typography`) |
| Radix UI Dialog | 1.1 | Product detail modals |

All pages are statically prerendered — there is no backend, database, or API route. The contact page uses `mailto:` links.

## Design System

**Palette — "Loro Piana" quiet luxury** (defined in `tailwind.config.ts`):

| Token | Hex | Use |
|-------|-----|-----|
| `ivory` | `#F3EEE6` | Backgrounds |
| `sienna` | `#9C8066` | Accents, links |
| `clay` | `#7D6A55` | Body text |
| `ecru` | `#EAE1D2` | Subtle backgrounds, borders |
| `basalt` | `#2E2B28` | Headings |
| `nickel` | `#BBAE9B` | Borders, secondary elements |

**Typography:** Cormorant Garamond (display) + Inter (body), loaded via `next/font` in `src/app/fonts.ts`.

## Project Structure

```
src/
├── app/
│   ├── layout.tsx          # Root layout: header, footer, metadata, viewport
│   ├── page.tsx            # Homepage
│   ├── collections/        # Product collections (mantels, architectural, outdoor, functional)
│   ├── works/              # Project portfolio
│   ├── process/            # Craft process
│   ├── commissions/        # Commission info
│   ├── contact/            # Contact details
│   ├── sitemap.ts          # Auto-generated /sitemap.xml
│   ├── robots.ts           # Auto-generated /robots.txt
│   ├── fonts.ts            # next/font setup
│   └── globals.css         # Global styles, animations
└── components/
    ├── Navigation.tsx      # Desktop menu + mobile bottom nav
    ├── ProductModal.tsx    # Radix dialog for product details
    ├── SectionTitle.tsx    # Shared section heading
    └── StructuredData.tsx  # Schema.org LocalBusiness JSON-LD

public/
├── favicon.ico             # Generated from shield logo
├── apple-touch-icon.png
└── images/                 # Hero, collections, gallery, logos
```

`scripts/scrape-101caststone.js` (run via `npm run scrape`, needs `puppeteer`) archived content from the previous site into `scraped-content/`; neither is used by the app at runtime.

## Development

```bash
npm install
npm run dev          # http://localhost:3000
```

```bash
npm run build        # Production build (static)
npm start            # Serve production build
npm run lint         # ESLint
npm run type-check   # tsc --noEmit
```

Requires Node.js 18+.

## SEO

- Per-page metadata with Open Graph + Twitter cards (`metadataBase: https://101caststone.com`)
- Schema.org `LocalBusiness` structured data with real NAP (name/address/phone)
- `sitemap.xml` and `robots.txt` generated by Next.js route handlers
- OG/social image: `/images/hero/winecountry.jpg`

## Deployment

Deployed on Vercel — zero config; every push builds a preview, and the production branch deploys to the live domain. To stay current on security patches, keep `next` on the latest release of its major line (`npm audit` will flag advisories).
